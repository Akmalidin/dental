==========================================================
  ODONTIS — ОФЛАЙН-ВЕРСИЯ. Установка в клинике
==========================================================

ЧТО ЭТО
  Программа работает на одном компьютере клиники («сервер») без интернета.
  Остальные компьютеры, ноутбуки и планшеты клиники открывают её в браузере
  по Wi-Fi. Когда есть интернет — кнопка «Синхронизация» обменивается
  данными с облаком (soft.stom.asia).

----------------------------------------------------------
1. ВЫБРАТЬ КОМПЬЮТЕР-СЕРВЕР
----------------------------------------------------------
  - Windows 10/11, включён весь рабочий день, подключён к Wi-Fi/сети клиники.
  - В роутере закрепить за ним постоянный IP (DHCP-резервирование),
    чтобы адрес для других компьютеров не менялся.

----------------------------------------------------------
2. УСТАНОВКА (удалённо через AnyDesk/RustDesk или на месте)
----------------------------------------------------------
  Вариант А — готовый SADAF.exe (собирается build_exe.bat):
    1) Создать папку, например C:\ODONTIS, положить туда SADAF.exe.
    2) Рядом создать файл offline_setup.json:
         {"url": "https://soft.stom.asia", "login": "логин директора", "password": "пароль"}
    3) Запустить SADAF.exe. Программа подключится к облаку, зарегистрирует
       этот компьютер и скачает данные клиники. Пароль после этого
       удаляется из файла — дальше синхронизация идёт по токену устройства.

  Вариант Б — из исходников (нужен Python 3.12, галочка "Add Python to PATH"):
       python -m venv venv
       venv\Scripts\pip install -r requirements_server.txt
       offline_setup.bat   (адрес облака, логин и пароль директора/админа)

  Брандмауэр Windows: разрешить входящие подключения на порт 8765
  (при первом запуске Windows спросит — нажать «Разрешить»).

----------------------------------------------------------
3. РАБОТА
----------------------------------------------------------
  - Запуск: SADAF.exe (или SADAF_Offline.vbs). Стоп: offline_stop.bat.
  - Другие компьютеры: адрес из боковой панели программы, например
    http://192.168.1.10:8765 — сделать закладку в браузере.
  - Синхронизация: кнопка «⟳ Синхронизация» в боковой панели.
    Без интернета работать можно сколько угодно — изменения копятся и
    уйдут при следующей синхронизации.

----------------------------------------------------------
4. ЧТО ВАЖНО ЗНАТЬ
----------------------------------------------------------
  - Конфликт: если одну запись меняли и офлайн, и в облаке — в облаке
    остаётся облачная версия, а офлайн-версия попадает в «Конфликты
    синхронизации» (в облаке), где можно выбрать нужную. Ничего не теряется.
  - Сотрудники, роли, филиалы, настройки клиники, кассовые смены —
    меняются только в облаке, офлайн их получает.
  - Пересечения записей в расписании (например, пациент записался через
    ИИ-ассистента на тот же час) показываются после синхронизации.
  - Фото/снимки, загруженные офлайн, в облако пока не передаются.
  - Резервные копии базы: папка backups (при каждом запуске и каждой
    синхронизации, хранятся последние 20).
  - Отключить компьютер от облака (утерян, заменён): суперадмин в облаке →
    «Офлайн-копии» → снять «Активно».

ОНЛАЙН-версия (если есть интернет): браузер → https://soft.stom.asia
